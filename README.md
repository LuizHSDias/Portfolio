## Instalação

Clone o repositório:

```bash
git clone https://github.com/LuizHSDias/Portfolio.git
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm start
```

Abra:

```text
http://localhost:3000
```
